# Blinded officer-intent panel

This development panel uses five fictional issuers and twenty independently authored HTML documents. Each issuer has a FY2024 and a FY2025 annual report with prior-year comparative columns, a FY2025 earnings-call transcript, and a FY2025 broker results review.

I used only the original HW4 handout text to design and label the panel. I did not inspect any existing fixture, benchmark report, implementation, retrieval output, or model result. Questions, reference answers, printed evidence groups, and visible source excerpts were fixed and sealed before retrieval or model scoring. I checked the authored HTML structure, the question and label keys and types, the cohort totals, and that each cited excerpt and printed evidence value occurs in its HTML source. I manually checked office timelines, fiscal years, units, and the two-company comparison when assigning labels.

The template cohort uses ordinary identity, succession, year, table, comparison, and document-specific fact questions. It includes paired historical CFO, COO, and CEO cases and two missing financial facts with officer wording. I predeclared four stress cases covering the day in a succession date, tenure in the CFO role, tenure with the employer, and a completed-month duration. Each answer fits the handout’s single-number, single-name, or `NOT_FOUND` format. The panel deliberately concentrates on historical officer intent and nearby controls.
